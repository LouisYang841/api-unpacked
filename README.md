# 把 API 讲明白

面向只用过官方聊天客户端的新手，主线是把模型接到第三方聊天应用：模拟创建并领取 API Key，先确认接口兼容类型及 Responses 支持情况，再填写服务商地址、密钥和模型，完成首次模拟对话。

采用中文教材的引导结构，以“学习目标—观察示例—动手操作—检查结果—本节小结”组织单栏分步内容。通过“上一步 / 下一步”学习，也可打开目录复习。学习路线：认识应用与服务商 → 领取密钥 → 选择兼容接口并连接应用 → 请求结构与 JSON → 拖拽请求 → 编辑 JSON → 故障排查 → 迁移清单。

每页的全部题目或操作任务完成后才可继续；按钮、目录与网址跳转遵守相同的前置条件，可自由返回复习。已移除独立地址章节和地址格式题。示例应用自动识别服务的域名、Base URL 或完整聊天 Endpoint；真实应用优先使用内置服务配置，必要时再核对文档。答对后显示简短彩纸效果，并在支持振动的设备上轻振 18 毫秒；重复点击同一已答对题目不会重复触发。

所有核心知识先讲解再练习。API Key 在浏览器内通过 Web Crypto 随机生成，使用明确的 `demo-key-` 教学前缀，不对应真实服务。随机值不写入仓库或浏览器存储；刷新后失效。可同时创建和管理多把密钥，三项练习接受任意未撤销的教学密钥。撤销仅让该密钥失效，并中断、清除使用该密钥的请求和练习结果，其他密钥不受影响；三项练习都必须先领取密钥，再携带正确的教学凭证。示例服务的三种地址写法会归一为同一个请求地址。

控制台按“创建 → 输入名称 → 确认生成 → 复制”的过程操作；列表展示名称、掩码、状态和创建时间，撤销需明确确认，可取消或按 Esc 关闭弹窗。名称使用文本显示，空名称不会生成密钥。

连接页选择 OpenAI / Anthropic / Gemini 兼容格式，并单独确认 Responses 支持。本虚构服务仅提供 OpenAI 兼容接口，同时支持 Chat Completions 与 Responses，开关会改变请求与响应预览。JSON 练习统一使用 Chat Completions 格式。应用连接填写地址 / 密钥 / 模型；拖拽填认证请求头 / 模型字段 / 提问；JSON 练习填请求头中的密钥及正文的两个值。应用连接按照“获取模型列表 → 选择模型 → 保存配置 → 检测连接 → 在聊天框发送”操作。保存、检测均不会发送聊天消息；修改地址或密钥后需要重新获取模型并保存，停用服务后不能发送。

成功发送后，模拟聊天窗口展示用户消息、验证与等待状态、逐段返回的预设回复。讲解动画在进入对应章节时自动循环播放；暂停会保留当前阶段，继续时接着播放，也可从头重播或单步查看。离开章节或浏览器后台时暂停；返回后尊重手动暂停状态。领取密钥和成功练习有简短反馈动画；“减少动态效果”模式关闭自动动画、彩纸和轻振，并直接显示完整回复。所有请求纯本地模拟，不会调用外部模型或保存真实凭证。

## 部署

推送到 `main` 后，GitHub Actions 会先检查教学逻辑和 JavaScript 语法，再将 `dist/` 发布到 GitHub Pages。也可以在 Actions 中手动运行 `Deploy GitHub Pages`。

仓库 Settings → Pages 的发布来源须为 **GitHub Actions**。

## 本地检查

需要 Node.js，无需安装依赖：

```sh
node check.cjs
node --check dist/app.js
node --check dist/lesson.js
```

用任意静态服务器提供 `dist/`，或直接打开 `dist/index.html` 查看页面。字体采用系统字体，不依赖外部资源。
