# 把 API 讲明白

面向只用过官方聊天客户端的新手，主线是把模型接到第三方聊天应用：模拟创建并领取 API Key，分清 API 基础地址与完整 Endpoint，再填写地址、密钥和模型，完成首次模拟对话。

采用单栏分步教材布局，每次显示一个步骤，通过“上一步 / 下一步”学习，也可打开目录返回复习。主线：认识应用与服务商 → 领取密钥 → 分清地址 → 连接应用。拓展：请求结构与 JSON → 拖拽请求 → 编辑 JSON → 故障排查 → 迁移清单。完成主线后可以直接跳到迁移清单。

所有核心知识先讲解再练习。API Key 在浏览器内通过 Web Crypto 随机生成，使用明确的 `demo-key-` 教学前缀，不对应真实服务。随机值不写入仓库或浏览器存储；刷新后失效。可同时创建和管理多把密钥，三项练习接受任意未撤销的教学密钥。撤销仅让该密钥失效，并中断、清除使用该密钥的请求和练习结果，其他密钥不受影响；三项练习都必须先领取密钥，再携带正确的教学凭证。地址练习演示三种应用路径拼接规则。

每项练习只需补三个关键空位：应用连接填地址 / 密钥 / 模型；拖拽填认证请求头 / 模型字段 / 提问；JSON 练习填请求头中的密钥及正文的两个值。每次成功发送都会在对应模拟聊天窗口展示用户消息、验证与等待状态、逐段返回的预设回复。领取密钥和成功练习附带简短反馈动画，支持“减少动态效果”。所有请求纯本地模拟，不会调用外部模型或保存真实凭证。

## 部署

推送到 `main` 后，GitHub Actions 会先检查教学逻辑和 JavaScript 语法，再将 `dist/` 发布到 GitHub Pages。也可以在 Actions 中手动运行 `Deploy GitHub Pages`。

仓库 Settings → Pages 的发布来源须为 **GitHub Actions**。

## 本地检查

需要 Node.js，无需安装依赖：

```sh
node check.cjs
node --check dist/app.js
node --check dist/lesson.js
```

用任意静态服务器提供 `dist/`，或直接打开 `dist/index.html` 查看页面。字体采用系统字体，不依赖外部资源。
